# Healia — Product Definition

## 1. Product

Healia is a calm, simple AI health consultation assistant that helps users describe their symptoms, answers relevant questions, and provides evidence-based health guidance.

Healia should feel like a **professional healthcare product**, not a generic AI chatbot.

## 2. Main Goal

Help a user go from:

**“I don't feel well and don't know what to do.”**

to:

**“I understand what may be going on, what I should do next, and when I should seek medical care.”**

## 3. Core User Journey

```text
Landing
   ↓
Start Consultation
   ↓
Health Assessment
   ↓
Processing
   ↓
Guidance / Results
```

The consultation may use voice as the primary interaction method.

## 4. Main Screens

### Landing

Purpose:

- Explain what Healia does
- Build trust
- Let the user start quickly

Primary action:

**Start Consultation**

Keep the page simple. No unnecessary feature sections.

### Consultation

Purpose:

- Collect the user's symptoms and relevant information
- Ask questions naturally
- Show the current conversation

Main elements:

- Voice interaction
- Conversation/transcript
- Listening/speaking state
- End consultation action

### Processing

Purpose:

- Clearly communicate that Healia is preparing the user's guidance

Show simple progress such as:

```text
Reviewing your symptoms
Checking medical references
Preparing your guidance
```

### Results

Purpose:

- Present the final guidance clearly

Main sections:

- Summary
- Possible concerns
- What you can do now
- Warning signs
- When to seek medical care
- Medical references
- Medical disclaimer

The result should be easy to scan rather than a large block of text.

### About / Privacy

Purpose:

- Explain what Healia is
- Explain limitations
- Explain privacy and data handling
- Provide the medical disclaimer

## 5. Visual Personality

Healia should feel:

- Calm
- Professional
- Trustworthy
- Clear
- Human
- Modern
- Minimal

It should **not** feel:

- Futuristic
- Flashy
- Corporate
- Like an AI startup landing-page template
- Like a social media app

## 6. Design Principles

1. Keep interfaces simple.
2. Give users one clear primary action.
3. Prioritize readability over decoration.
4. Use whitespace generously.
5. Make important medical information visually obvious.
6. Avoid unnecessary cards and sections.
7. Avoid excessive animations.
8. Keep navigation simple.
9. Make the voice consultation feel central.
10. Never sacrifice clarity for visual style.

## 7. Scope

### Include

- Landing page
- Consultation flow
- Voice interaction
- Conversation/transcript
- Assessment state
- Processing state
- Results
- Medical references
- Disclaimer
- Privacy information
- Responsive mobile and desktop layouts

### Do Not Include Yet

- User dashboard
- Complex accounts/profile system
- Social features
- Appointment booking
- Payments
- Community features
- Large marketing website
- Unnecessary AI features
- Complex animations
- Excessive personalization

## 8. Overall Principle

**Simple enough to understand immediately.
Professional enough to trust.
Beautiful enough to feel polished.**
